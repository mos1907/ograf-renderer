Step 1
Design in OGraf Studio

Open OGraf Studio — a free, open-source browser-based editor by ZeroDensity. No installation needed: download and run, or build from source.

→ Visual authoring — compose text, images, shapes and editable vector paths in a dockable workspace
→ Lottie animations — import Lottie files or animate with independent property tracks and easing
→ AI assistance — built-in AI chat and MCP agents to generate and edit layers and animations
browser-based open-source free

Step 2
Bind Live Data

Bind text, images and colors to operator fields using the GDD schema. Define data types (string, integer, color) so the OGraf Renderer control panel generates matching input fields automatically.

→ Brand Kits — reusable style packs, components and patterns for consistency
→ Custom actions — define goal, VAR, substitution or any sport/news action

→ Data fields are generated from the manifest schema
